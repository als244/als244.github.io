Current Work

Training large, long-context models at near-peak throughput using minimal GPU memory via prefetching and evictions overlapped with computation.

ShadowSpill: A system for DNN training within strict memory budgets. It automatically plans what stays on the GPU and what spills to slower memory. Its planner jointly handles offloading, micro-batch sizing and scheduling, recomputation, and parallelism/sharding --- searching across a large space of execution paths not accessible from traditional training engines. The system's runtime executes the plan and handles async data transfers, dependency tracking, and memory management. ShadowSpill is a general compilation+runtime and is compatible with arbitrary PyTorch-compilable models.

Playground: Dataflow Simulator, a simplified version of the ShadowSpill planner that uses theoretical hardware constants to show the benefits of effective offloading.

About Me

Hi, I'm Andrew Sheinberg. I'm a fourth-year Computer Science PhD student at Princeton University, advised by Professor Kai Li. Before Princeton, I studied Computer Science & Mathematics at Yale. I grew up in Barrington, RI.

I build systems software for machine learning. Accelerators keep getting faster, but their memory is expensive and the links to the rest of the system are slow by comparison, so the hard part is often deciding where data lives and when it moves. My recent work borrows classic operating-systems ideas, like working sets and prefetching, to train large, long-context models at near-peak throughput with a fraction of the GPU memory they would otherwise need.
